# Spec Delta

## Purpose

提供简洁的 A 股市场快照，让用户在进入个股研究前快速判断指数强弱、市场宽度与板块方向。该能力只做聚合展示，不提供全市场条件选股或扫描入口。

## ADDED Requirements

### Requirement: 指数看板

系统 MUST 在首页展示可配置的 A 股核心指数（至少包含上证指数、深证成指、创业板指、沪深 300），每个指数显示最新点位、涨跌幅与数据时间。

#### Scenario: 展示核心指数
- **WHEN** 用户打开首页
- **THEN** 系统展示已配置指数的点位、涨跌幅与最近更新时间

#### Scenario: 配置指数
- **WHEN** 用户启用或停用一个指数卡片
- **THEN** 首页按新配置展示，刷新后配置仍然保留

### Requirement: 市场宽度

系统 MUST 基于最近交易日展示上涨、下跌、平盘家数，并在数据源可得时展示涨停、跌停家数与两市成交额；所有指标 MUST 标注交易日与数据时间。

#### Scenario: 上涨下跌家数
- **WHEN** 最近交易日数据完整
- **THEN** 首页展示上涨、下跌、平盘家数，且三者之和不超过当日有行情证券数

#### Scenario: 涨停数据缺失
- **WHEN** 数据源不提供涨停家数
- **THEN** 系统显示“数据不可用”占位，不用 0 冒充真实值

### Requirement: 板块排行

系统 MUST 展示行业或概念板块的涨跌幅排行，至少包含涨跌幅、领涨股与成交额；默认展示涨幅与跌幅前若干名，具体数量可配置。

#### Scenario: 查看板块排行
- **WHEN** 用户打开首页板块区域
- **THEN** 系统按涨跌幅展示板块排行，并标注板块类型与交易日

#### Scenario: 板块数据延迟
- **WHEN** 板块数据比其他行情数据晚到
- **THEN** 板块区域显示自己的更新时间，不阻塞指数与市场宽度展示

### Requirement: 最近交易日标识

系统 MUST 明确区分“今日”和“最近交易日”；在周末、节假日或数据尚未更新时，首页 MUST 显示“最近交易日”而不是“今日”。

#### Scenario: 周末访问
- **WHEN** 用户在周六打开首页
- **THEN** 页面显示“最近交易日：YYYY-MM-DD”，不出现“今日行情”文案

#### Scenario: 盘中数据未更新
- **WHEN** 交易日收盘后日线尚未同步完成
- **THEN** 页面显示上一交易日数据，并显示“数据更新中”或“数据截至上一交易日”

### Requirement: 数据来源与时间戳

首页每类数据 MUST 展示数据来源与更新时间的可访问说明；单个数据源失败 MUST NOT 导致整个首页白屏。

#### Scenario: 单个数据源失败
- **WHEN** 板块数据源超时但指数数据正常
- **THEN** 指数与市场宽度正常展示，板块区域显示错误占位与重试入口

#### Scenario: 查看数据说明
- **WHEN** 用户点击数据时间或来源标识
- **THEN** 系统展示数据来源、统计口径与最近更新时间

### Requirement: 指数与板块详情

系统 MUST 提供指数详情页与板块详情页：指数详情展示最新行情、成分/权重（可得时）与数据时间；板块详情展示板块行情、成员与数据时间。数据不可用时 MUST 显示明确占位与重试入口。

#### Scenario: 指数详情
- **WHEN** 用户进入上证指数详情页
- **THEN** 系统展示指数最新点位、涨跌幅、成交额、成分/权重（可得时）与数据日期

#### Scenario: 板块详情
- **WHEN** 用户进入某行业板块详情页
- **THEN** 系统展示板块涨跌幅、成员列表与成员行情（可得时），并标注数据时间

#### Scenario: 成分数据缺失
- **WHEN** 指数或板块成分数据不可用
- **THEN** 页面展示“成分数据暂不可用”与重试入口，不展示伪造成分

### Requirement: 导航到个股或板块

系统 MUST 允许用户从指数卡片或板块排行进入对应详情页；首页 MUST NOT 提供“扫描全市场”“全市场选股”或“批量筛选”入口。

#### Scenario: 点击指数
- **WHEN** 用户点击上证指数卡片
- **THEN** 系统进入指数详情页并展示该指数的行情与成分信息（可得时）

#### Scenario: 无全市场扫描入口
- **WHEN** 用户浏览首页
- **THEN** 页面不存在全市场条件筛选、排名扫描或批量分析入口

### Requirement: 首页性能与缓存

首页 MUST 优先使用缓存渲染，缓存命中时首屏 LCP MUST 小于等于 2.5 秒；缓存过期时 MUST 先展示旧数据并标注更新时间，再后台刷新。

#### Scenario: 缓存命中
- **WHEN** 用户在工作日打开首页且缓存有效
- **THEN** 指数、市场宽度与板块区域在 2.5 秒内完成首屏渲染

#### Scenario: 缓存过期
- **WHEN** 缓存超过配置的过期时间
- **THEN** 系统先展示旧数据与“更新中”标识，刷新完成后再替换
