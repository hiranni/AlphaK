# Spec Delta

## Purpose

让用户通过代码、名称或拼音快速找到任意 A 股证券，并在一页内查看价格、K 线、技术指标、公司资料与财务概览。该能力只做单标的检索与研究，不做全市场筛选或排名。

## ADDED Requirements

### Requirement: 证券搜索

系统 MUST 支持按证券代码、名称与拼音首字母搜索 A 股证券；搜索 MUST 有防抖与键盘上下选择，无结果时 MUST 显示明确提示与搜索建议。

#### Scenario: 按代码搜索
- **WHEN** 用户输入 `600519`
- **THEN** 搜索结果首项为贵州茅台，并显示代码、名称与交易所

#### Scenario: 按拼音首字母搜索
- **WHEN** 用户输入 `gzmt`
- **THEN** 搜索结果包含贵州茅台

#### Scenario: 无搜索结果
- **WHEN** 用户输入不存在的关键词
- **THEN** 系统显示“未找到匹配证券”，并保留搜索框可继续输入

### Requirement: 个股详情头部

系统 MUST 在个股详情页展示最新价、涨跌幅、成交量、成交额、换手率、总市值、流通市值、52 周高低与数据时间；价格颜色 MUST 遵循用户的涨跌颜色偏好。

#### Scenario: 展示详情头部
- **WHEN** 用户进入某股票详情页
- **THEN** 页面在头部展示上述字段，并标注数据截至时间

#### Scenario: 停牌或数据缺失
- **WHEN** 股票停牌或某字段缺失
- **THEN** 对应字段显示“—”或“停牌”，不使用 0 代替缺失值

### Requirement: 个股详情深链接

系统 MUST 支持 `/stock/{symbol}` 形式的深链接；无效或不存在的代码 MUST 返回友好的 404 页面并提供搜索入口，不得白屏或暴露堆栈。

#### Scenario: 直接访问深链接
- **WHEN** 用户访问 `/stock/600519.SH`
- **THEN** 系统直接打开该股票详情页

#### Scenario: 无效代码
- **WHEN** 用户访问 `/stock/999999.SH`
- **THEN** 系统展示 404 页面、错误说明与搜索框

### Requirement: K 线与周期

系统 MUST 提供日、周、月 K 线，并支持不复权、前复权、后复权切换；默认 MUST 使用前复权。分钟线不属于 MVP 范围。

#### Scenario: 切换周期
- **WHEN** 用户从日线切换到周线
- **THEN** 图表按周聚合展示，成交量与指标同步重算

#### Scenario: 切换复权
- **WHEN** 用户切换到后复权
- **THEN** 图表使用后复权价格，页面显示当前复权方式

### Requirement: 技术指标

系统 MUST 支持 MA、EMA、BOLL、MACD、KDJ、RSI 与成交量指标；指标参数 MUST 可调整，计算口径 MUST 文档化，并使用固定样本进行回归校验。

#### Scenario: 叠加指标
- **WHEN** 用户启用 MACD 与 KDJ
- **THEN** 图表在副图展示两个指标，参数与颜色可识别

#### Scenario: 指标校验
- **WHEN** 使用固定历史样本运行指标校验
- **THEN** 计算结果与基准实现的差异可解释，并在允许误差内

### Requirement: 基本面展示

系统 MUST 展示公司资料、利润表、资产负债表、现金流量表、核心财务指标与估值分位；每条财务数据 MUST 标注报告期与公告日期，缺失值 MUST 显示“—”并注明原因。

#### Scenario: 查看财务三表
- **WHEN** 用户打开财务页签
- **THEN** 系统展示三表数据，支持年度/季度与同比/环比切换

#### Scenario: 估值分位
- **WHEN** 用户查看 PE/PB 历史分位
- **THEN** 系统展示样本区间、当前值与分位，并说明计算口径

### Requirement: 公司资料

系统 MUST 展示公司全称、主营业务、所属行业、上市日期、实际控制人、网站、地区与简介，并标注数据来源与更新时间；缺失字段 MUST 显示“—”，不得用空字符串或推测值代替。

#### Scenario: 查看公司资料
- **WHEN** 用户打开个股“公司资料”页签
- **THEN** 系统展示公司资料字段、来源与更新时间

#### Scenario: 公司资料缺失
- **WHEN** 某证券的公司资料尚未同步
- **THEN** 页面显示“暂无公司资料”与重试入口，不影响 K 线与财务页签

### Requirement: 市值与估值指标

系统 MUST 从每日基础指标展示总市值、流通市值、PE(TTM) 与 PB，并标注对应交易日；数据缺失时 MUST 显示“—”，不得用 0 或报告期估值冒充每日估值。

#### Scenario: 市值展示
- **WHEN** 用户查看个股头部
- **THEN** 总市值与流通市值来自最近交易日的每日基础指标，并显示日期

#### Scenario: 估值缺失
- **WHEN** 某股票当日 PE/PB 缺失
- **THEN** 对应字段显示“—”，质量报告记录缺失原因

### Requirement: 页签与加载体验

个股详情 MUST 使用页签组织概览、K 线、财务与公司资料；切换页签 MUST NOT 触发整页刷新，已加载数据 MUST 可复用。

#### Scenario: 切换页签
- **WHEN** 用户从概览切换到 K 线
- **THEN** 页面局部更新，导航与头部信息保持稳定

#### Scenario: 首屏性能
- **WHEN** 用户打开已缓存的个股详情
- **THEN** 首屏在 2 秒内可用，K 线在 1.5 秒内完成渲染

### Requirement: 单标的研究边界

个股研究 MUST 只针对当前标的；系统 MUST NOT 在该能力内提供全市场条件筛选、全市场排名或批量扫描入口，也不得在用户不知情时拉取全市场数据做横向计算。

#### Scenario: 无全市场扫描
- **WHEN** 用户浏览个股详情页
- **THEN** 页面不存在“筛选全市场”“全市场排名”或“批量分析”入口

#### Scenario: 行业对比边界
- **WHEN** 用户查看行业对比
- **THEN** 系统只允许与用户指定的少量标的（不超过 8 只）对比，不展示全行业全量排名
