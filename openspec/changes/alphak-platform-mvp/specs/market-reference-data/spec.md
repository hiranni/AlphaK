# Spec Delta

## Purpose

为市场概览与个股研究提供可追溯的参考数据：指数目录与行情、指数成分、板块成员、每日股本/市值/估值与公司资料。该能力只服务检索、详情和聚合展示，不提供全市场扫描。

## ADDED Requirements

### Requirement: 指数目录与日行情

系统 MUST 维护指数目录（代码、名称、市场、类别、状态）与指数日行情（开高低收、成交量、成交额），并以指数代码和交易日建立唯一约束；指数行情缺失时 MUST 显示“数据不可用”，不得用 0 代替。

#### Scenario: 导入核心指数
- **WHEN** 初始化任务同步指数目录与最近交易日行情
- **THEN** 系统保存至少上证指数、深证成指、创业板指、沪深 300，并可在首页与详情页查询

#### Scenario: 指数行情缺失
- **WHEN** 某指数在最近交易日没有行情
- **THEN** 指数卡片显示“数据不可用”与最后可用日期

### Requirement: 指数成分

系统 MUST 保存指数成分与权重历史，包含调入日期、调出日期与权重；历史查询 MUST 按查询日期返回当时成分，不能用最新成分回填历史。

#### Scenario: 查看指数详情成分
- **WHEN** 用户打开指数详情页
- **THEN** 系统展示当前成分与权重（可得时），并标注数据日期

#### Scenario: 历史成分回放
- **WHEN** 查询过去某日的指数成分
- **THEN** 系统返回该日期有效的成分，不包含之后才调入的证券

### Requirement: 板块目录与成员

系统 MUST 维护行业板块目录与成员；概念板块在数据源可得时提供，不可得时 MUST 明确标注“仅行业”。板块成员 MUST 保存生效区间，支持历史查询。

#### Scenario: 行业板块排行
- **WHEN** 首页计算板块排行
- **THEN** 系统使用行业板块成员与最新日线计算涨跌幅、领涨股与成交额

#### Scenario: 概念板块缺失
- **WHEN** 数据源不提供概念板块
- **THEN** 页面显示“仅行业板块”，不伪造概念分类

### Requirement: 每日基础指标

系统 MUST 按证券与交易日保存总股本、流通股本、总市值、流通市值、PE(TTM)、PB 与换手率，并与同日日线对齐；市值 MUST 由收盘价与对应股本计算，缺失字段 MUST NOT 推算或填 0。

#### Scenario: 个股头部市值
- **WHEN** 用户打开个股详情
- **THEN** 系统展示总市值、流通市值、PE(TTM) 与 PB，并标注数据日期

#### Scenario: 股本缺失
- **WHEN** 某证券当日股本数据缺失
- **THEN** 市值与估值显示“—”，质量报告记录缺失

### Requirement: 公司资料

系统 MUST 保存公司全称、主营业务、所属行业、上市日期、实际控制人、网站、地区与简介，并记录来源与更新时间；人工修正 MUST 留痕，冲突字段保留原值与修正值。

#### Scenario: 查看公司资料页签
- **WHEN** 用户打开个股“公司资料”页签
- **THEN** 系统展示公司资料字段与更新时间，缺失字段显示“—”

#### Scenario: 人工修正
- **WHEN** 管理员修正某公司实际控制人
- **THEN** 系统保存修正值、原值、操作人与时间，并在质量报告标记

### Requirement: 参考数据同步与质量

指数、板块、每日基础指标与公司资料 MUST 通过统一适配器同步，支持全量/增量、幂等写入、失败重试与断点续传；每个数据集 MUST 生成覆盖率、缺失数、最后更新时间与异常清单。

#### Scenario: 增量同步
- **WHEN** 收盘后同步任务运行
- **THEN** 系统只更新缺失或变更的参考数据，重复执行不产生重复记录

#### Scenario: 覆盖率报告
- **WHEN** 管理员打开数据管理页
- **THEN** 系统展示各参考数据集的覆盖率、缺失、异常与最后更新时间

### Requirement: 参考数据边界

参考数据 MUST 只用于证券检索、指数/板块详情、市场聚合与个股研究；系统 MUST NOT 提供基于参考数据的全市场条件筛选、排名扫描或批量分析入口。

#### Scenario: 无全市场筛选
- **WHEN** 用户浏览指数、板块或公司资料页面
- **THEN** 页面不存在“筛选全市场”“全市场排名”或“批量扫描”入口

#### Scenario: 聚合展示
- **WHEN** 首页展示板块排行
- **THEN** 系统只展示聚合结果，不暴露逐只扫描或批量导出全市场明细的入口
