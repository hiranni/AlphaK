# Spec Delta

## Purpose

提供安全、可自托管的 Web 运行基础：本地单用户访问、偏好设置、健康检查、备份恢复与明确的 MVP 边界。该能力确保 AlphaK 可以在一台机器上启动、使用和恢复，而不依赖桌面客户端或外部账号体系。

## ADDED Requirements

### Requirement: 纯 Web 访问

系统 MUST 以纯 Web 形式提供全部 MVP 功能，用户通过浏览器访问；MUST NOT 要求安装 Electron、Tauri 或其他桌面客户端，也不得依赖本地原生插件才能完成核心流程。

#### Scenario: 浏览器直接使用
- **WHEN** 用户启动服务并在浏览器打开首页
- **THEN** 行情、个股、自选与设置功能均可使用，无需安装额外客户端

#### Scenario: 无桌面安装包
- **WHEN** 用户查看发布物
- **THEN** 不存在桌面安装包或强制下载客户端的提示

### Requirement: MVP 仅回环访问

MVP 的宿主机直跑服务 MUST 只监听 `127.0.0.1`；MUST NOT 提供远程/局域网访问开关，也 MUST NOT 监听 `0.0.0.0`。启动日志 MUST 明确打印当前绑定地址。Docker 目标（非当前 MVP 验收）允许容器内 API 监听私有 bridge 地址，但宿主机只发布 web 到回环，API/数据库/Redis 不发布；网络边界见 `design.md` §16。

#### Scenario: 默认启动
- **WHEN** 用户使用默认配置启动服务
- **THEN** 服务只监听 `127.0.0.1`，局域网其他设备无法直接访问

#### Scenario: 尝试非回环绑定
- **WHEN** 配置请求监听 `0.0.0.0` 或非回环地址
- **THEN** 系统拒绝启动并提示“MVP 仅支持本机访问”

### Requirement: 用户偏好设置

系统 MUST 支持主题（亮/暗）、涨跌颜色、默认首页、时区与列表密度设置；设置 MUST 在刷新与重启后保留，并 MUST 只影响当前用户。

#### Scenario: 修改主题
- **WHEN** 用户切换到暗色主题
- **THEN** 页面立即生效，刷新后仍为暗色

#### Scenario: 时区设置
- **WHEN** 用户选择 `Asia/Shanghai`
- **THEN** 页面时间与“最近交易日”判断使用该时区，并在设置页显示

### Requirement: 设置页

系统 MUST 提供可访问的设置页，至少包含主题、涨跌颜色、默认首页、时区、轮询间隔、数据源状态、备份/恢复入口与版本信息；修改 MUST 立即生效或在保存后生效，并持久化。

#### Scenario: 打开设置页
- **WHEN** 用户打开设置页
- **THEN** 页面展示偏好、数据源状态、备份入口与版本信息

#### Scenario: 修改设置
- **WHEN** 用户修改默认首页并保存
- **THEN** 刷新后首页跳转到新默认页，设置值保留

### Requirement: 可观测性

系统 MUST 记录结构化日志、请求耗时、任务成功率与错误追踪；关键失败（数据同步、健康检查、备份恢复）MUST 可告警。日志与指标 MUST 脱敏，不包含密钥或完整凭据。

#### Scenario: 数据同步失败告警
- **WHEN** 日线同步连续失败达到阈值
- **THEN** 系统产生告警事件，并在数据管理页与健康检查中可见

#### Scenario: 请求指标
- **WHEN** 用户访问常用接口
- **THEN** 系统记录路径、状态码、耗时与 request_id，用于排查性能问题

### Requirement: 健康检查

系统 MUST 提供健康检查接口，返回应用、数据库、缓存与数据源连接状态；响应 MUST NOT 包含密钥、连接串或堆栈信息。

#### Scenario: 全部依赖正常
- **WHEN** 运维访问健康检查
- **THEN** 系统返回应用、数据库、缓存和最近一次数据同步状态

#### Scenario: 数据库不可用
- **WHEN** 数据库连接失败
- **THEN** 健康检查返回非健康状态与可读错误分类，不返回连接串或凭据

### Requirement: 备份与恢复

系统 MUST 提供数据库与配置的备份与恢复流程；恢复 MUST 先校验备份完整性，并在恢复前创建当前状态备份；恢复后 MUST 能通过健康检查与关键页面验证。

#### Scenario: 创建备份
- **WHEN** 管理员触发备份
- **THEN** 系统生成包含数据库与必要配置的备份文件，并记录时间、大小与校验值

#### Scenario: 恢复备份
- **WHEN** 管理员选择有效备份执行恢复
- **THEN** 系统先校验备份、再备份当前状态、完成恢复并通过健康检查

#### Scenario: 损坏备份
- **WHEN** 备份文件校验失败
- **THEN** 系统拒绝恢复并说明原因，不修改当前数据

### Requirement: 一键启动与初始化

项目 MUST 提供本地一键启动方式：当前切片为 `cargo run` + `npm run dev`，完整 MVP 目标为 Docker Compose。首次启动 MUST 在 30 分钟内完成数据库初始化、证券列表与基础行情导入，并提供可访问的首页。

#### Scenario: 首次启动
- **WHEN** 用户执行启动命令
- **THEN** 服务启动、数据库迁移完成，并在初始化任务完成后可访问首页

#### Scenario: 初始化失败
- **WHEN** 数据源在初始化期间不可用
- **THEN** 系统保留已完成步骤、显示失败原因与重试入口，不要求从头开始

### Requirement: 日志与敏感信息

系统 MUST 输出结构化日志，记录请求、任务与错误；日志 MUST 对密钥、Token、Cookie 与用户敏感字段脱敏，MUST NOT 记录完整请求体中的凭据。

#### Scenario: 任务失败日志
- **WHEN** 数据同步任务失败
- **THEN** 日志包含任务 ID、数据集、错误分类与重试次数，不包含数据源密钥

#### Scenario: 请求日志
- **WHEN** 用户访问设置页
- **THEN** 日志记录路径、状态码与耗时，不记录敏感配置值

### Requirement: 合规提示

首页、个股详情与设置页 MUST 展示免责声明与数据来源说明；系统 MUST NOT 出现“荐股”“收益承诺”或“实盘交易”入口。

#### Scenario: 查看免责声明
- **WHEN** 用户打开首页或个股详情
- **THEN** 页面页脚展示“仅供研究、不构成投资建议”的说明

#### Scenario: MVP 边界
- **WHEN** 用户浏览导航
- **THEN** 不存在虚拟盘、Agent 执行、策略回测或实盘交易入口

### Requirement: MVP 范围边界

本能力 MUST NOT 实现股票池、策略回测、虚拟盘、Agent 执行、可解释回放或多用户权限；相关入口 MUST 不出现或明确标注“后续版本”，避免用户误以为可用。

#### Scenario: 导航边界
- **WHEN** 用户查看主导航
- **THEN** 只出现 MVP 已有能力，未实现能力不以可点击入口出现

#### Scenario: 未实现接口
- **WHEN** 客户端请求未实现的策略或虚拟盘接口
- **THEN** 系统返回 404 或明确的“未开放”错误，不返回伪造数据
