# Proposal

## Why

AlphaK 的目标是成为一个可自托管、数据可插拔的 A 股研究工作台。规划时仓库只有需求文档与机读契约；当前已有一个 Rust/Axum + SQLite + Vite/React 的演示垂直切片。本 change 继续交付 MVP 基础版，把「行情 → 个股 → 自选 → 研究 → 数据运维」这条日常链路跑通，为后续股票池、虚拟盘、Agent 执行与可解释回放打地基。

## What Changes

- 新建纯 Web 的 AlphaK MVP：A 股市场概览、指数/板块详情、证券搜索与个股详情、公司资料、自选股、K 线与常用技术指标、基本面概览。
- 建立数据底座：证券主数据、交易日历、日线、财务数据，以及指数/板块目录与成分、每日基础指标、公司资料；数据源适配器、增量同步、质量检查、失败重试与补数。
- 行情采用开源免费多数据源：按数据集建立独立主备（首批为个股日线、行情快照与指数数据；小样本实测后暂定腾讯主、东财备），不使用一条通用备用链；先小样本实测连通性、字段口径与故障切换，再确定默认优先级。
- MVP 固定本地单用户：默认仅监听 `127.0.0.1`，浏览器直接访问；远程/局域网访问移出 MVP。
- 初始化两阶段：应用与最近数据 30 分钟内可用，近 10 年历史由后台异步回填。
- 偏好设置与备份/恢复：主题、涨跌颜色、默认首页、时区、轮询间隔；数据库与配置的可恢复备份。
- API 契约与可观测性：OpenAPI + 生成 TypeScript client；请求/任务指标、错误追踪与告警。
- 遵循 `docs/specs` 的文档与数据契约；本 change 不实现 Agent、虚拟盘或回放，但为它们保留数据边界。
- 明确不做：全市场扫描/条件选股、股票池、策略回测、虚拟盘、Agent 执行、可解释回放、多用户、实盘交易。

## Capabilities

### New Capabilities

- `market-data`: 证券主数据、交易日历、日线与财务数据的接入、适配器、同步任务、质量检查与补数。
- `market-reference-data`: 指数/板块目录与成分、每日股本与估值、公司资料，以及对应的覆盖率与质量检查。
- `market-overview`: 指数看板、涨跌分布、板块排行与数据时间戳。
- `stock-research`: 全局搜索、个股详情、K 线与技术指标、基本面展示。
- `watchlist`: 自选股分组、排序、备注、批量导入导出与行情刷新。
- `platform-foundation`: 本地单用户启动、Web 访问边界、偏好设置、健康检查与备份恢复。

## Impact

- 新增 Web 前端、API 服务、数据同步任务与数据库迁移；使用 Rust/Axum + SQLite + Vite/React，直接本机运行，不依赖 Docker。
- 新增 `market-data` 与 `market-reference-data` 适配器边界。MVP 行情使用开源免费公开接口：首批接入东财、腾讯两源，按数据集分别配置主备，不做通用 fallback；新浪作为交叉校验/候补，巨潮用于财务与公告，通达信在后续批次评估。
- 数据源成功条件：数据日期、覆盖范围、字段口径与质量校验通过并事务入库；支持部分成功、缺口补齐、限时重试、来源冷却与后续自动重试。全部来源失败时保留最后成功数据并显示过期状态，禁止自动回退 mock 或演示种子。
- 不复权行情与复权因子分别管理，记录来源与批次；发布严格限定本次任务范围。AxData 仅作为公开接口与字段口径参考，不引入其 Python 运行时、DuckDB/Parquet 或数据库。
- 新增本地直接运行方式与备份脚本；不引入 Docker/其他数据库。
- 不修改现有 `docs/specs` 契约；新增实现必须遵守 8 只上限、禁全市场扫描、禁实盘等全局约束。
- 数据源边界：AlphaK 为个人研究/非商业用途；公开接口不等于官方授权，ToS、限频与再分发约束仍需逐项核对（10.8）。
- 影响后续 change：股票池、回测、虚拟盘、Agent 与回放将复用本 change 的数据模型、搜索、图表与本地运行基础。
