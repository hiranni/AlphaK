# ak-state-v1 · 历史状态学习

## 0. 阅读摘要与执行边界

本专篇结合[公共方法](common-methodology.md)阅读，模型不绑定具体股票或Agent；股票、预算和Agent仅由实例配置。公共数据处理、时间验证、上下文、永久账本与解释缓存规则对本模型全部生效。本文数学设计不是可执行DSL，也不是已部署承诺。

## 1. 实现状态核验

截至2026-10-26，当前状态：**已接入 · 日线试验适配 pilot-gates-1**。核对源：`trading_research.rs::state/prediction/forecast/analyze/run`，以及`model-calculation-contracts.json`对应ID。

现有模型门槛：Bₜ≥0.25。当前只使用近邻状态估计，不声称拟合了完整市场状态模型。

## 2. 模型分析与假设

假设相近的历史价格、成交与情绪状态具有相近的条件收益分布。估计对象是 $m(x)=E[y^{(5)}\mid x]$，不是下一日涨跌标签。局部相似并不意味着机制相同；市场制度和个股基本面改变会破坏此假设。

## 3. 特征与数据处理

当前七维为 $x=[R_5,R_{20},d_{20},\max(\sigma_{20},0.003),RV,DD_{60},B]$。20日波动使用21个价格形成20个收益，ddof=0；量均值不含当日；60日高点包含当日收盘。量均值0被实现为量比0，属于待修缺失语义。收益、波动与回撤为小数，RV为倍数，B为比例。所有历史样本情绪必须对应其日期。

## 4. 当前数学模型与推导

训练集合 $T_t(W)=\{j:60\le j<t,j+6<t,j+W\ge t,B_j\text{可用}\}$，至少40行。$y_j=O_{j+6}/O_{j+1}-1$。用训练段总体标准差 $s_l\ge10^{-5}$ 构造

$$d^2(j,t)=\sum_{l=1}^7 clip((x_{jl}-x_{tl})/s_l,-5,5)^2.$$

训练均值在距离差中抵消；代码计算并输出均值，但不需要先中心化两份数据。截断的是“差值标准化后”，不是分别截断两个z值，这两种算法不同。按距离排序、相同距离按历史索引升序，取k个近邻等权。最小二乘局部常数的一阶条件给出 $\hat\mu=k^{-1}\sum y_j$。

$$u=sd(y)/\sqrt{\max(k/5,1)},\quad D=\max(0.02,-y_{(\lfloor0.1(k-1)\rfloor)}),\quad e=\hat\mu-0.002-\kappa u.$$

排序索引从0起，经验分位不插值。u的有效样本折扣是启发式，不是经过估计的置信区间。近邻可能共享标签窗口，不能假定独立。

## 5. 训练、调优与收敛

当前W∈{80,120}、k∈{8,16,24}、κ∈{0,0.5,1}，共18组。过去40步内从max(t−40,110)到t−6（不含）每5步验证，至少4事件。每次验证重新用该时点之前的成熟标签训练。回报 $a_v=1_{e_v>0}(y_v-0.002)$，目标 $J=mean(a)-0.5sd(a)$。选J最大的组合，相同分数保留循环中先遇到的组合。J≤0不产生买入候选。

有限枚举必终止，但固定k和小窗口没有统计一致性保证。候选选择未使用完整门槛、仓位或成交，因此J不是策略样本外收益。升级应增加时序外层验证、近邻距离拒绝、独立事件有效样本统计，并做相关性和维度消融。kNN渐近条件及非平稳限制见公共方法第7节。

## 6. B/S、仓位与情绪

当前gate为B≥0.25；gate、e>0、J>0同时成立输出buy_candidate，否则wait。参考上限为公共公式，账户参考上限再乘用户资金权重。当前不读取持仓，不输出可执行卖出；报告里的5步到期与8%复核是说明，不是退出引擎。B进入距离也进入门槛，应做仅门槛/仅特征/均不用的对照避免重复过滤。

## 7. 可执行升级与验证

以当前版本为V0，升级版本必须独立ID/版本；先将零量缺失、真实日历、公司行动和完整成本修正，再比较局部岭回归与等权kNN。主实验比较净收益、最大回撤、覆盖、成交拒绝、换手；必须同时报告远距离无支持状态。未来价格扰动不改变过去预测、相同距离排序确定、j+6=t被排除应成为测试。任何无足够近邻或预处理失效返回blocked。
