# AlphaK 模型公共方法与计算口径

版本：design-2026-10-26.1；状态：研究规范。本文与每个模型专篇共同构成完整研究文档，不是运行代码或已验证策略。现行实现以 `apps/api/src/trading_research.rs` 为准；数学设计不自动进入现有表达式 DSL。

## 1. 边界、符号与时间

每个实例仅使用人工冻结的 1–8 只沪深股票；不扫描全市场。市场指数和已发布宽度聚合是参考输入，不授权遍历全市场证券。模型无 Agent 绑定；绑定属于实例。当前仅研究输出，无账户撮合。未来决策也必须遵守 INV-01–16、schema 和账户业务校验，模型不得直接写订单。

$t$ 为交易所交易日索引，$\mathcal F_t$ 为截至决策时刻实际可用的信息集合；$O,H,L,C,V,A$ 为开、高、低、收、成交量与成交额；$h$ 为持有交易日；收益率均为小数，量比为倍数，资金在模型层用元、账本存分。

标准标签定义为收盘 $t$ 决策、下一交易日开盘进入，持有 $h$ 个开盘间隔：

$$y_{i,t}^{(h)}=\frac{O^{TR}_{i,t+h+1}}{O^{TR}_{i,t+1}}-1,\qquad h\in\{5,10,20\}.$$

$O^{TR}$ 是具备历史可用公司行动口径的总回报价格，或由原始价格与现金/股数事件计算的等价财富比，不能用未来复权因子污染历史特征。信号价格和可成交原始价分离。上述是无提前退出的研究标签，含止损的策略回测须按事件逐笔执行，不能直接复用此标签充当策略收益。

标签可用时间由退出时刻及数据发布延迟确定；训练必须满足 `label_available_at < decision_at`。停牌导致不可成交时记录延迟/拒绝，不能假定原计划开盘成交。当前适配器以有效观测步代替完整交易日，且未复权；不得称为严格交易日/PIT标签。

## 2. 数据处理与输入表

| 数据 | 必需字段与单位 | 可用时间与处理 | 缺失/异常 |
| --- | --- | --- | --- |
| 日线 | symbol、交易日、OHLC（元）、volume（股）、amount（元） | 收盘确认后，校验时区、来源、OHLC包络、非负量；记录抓取时间和修订版本 | 禁止补未来价；交易所开市但缺行情标记缺失，停牌为独立状态 |
| 公司行动 | 除权日、公布时间、分红、拆并股比例 | 当时已知事件；收益按持股财富处理 | 缺关键事件阻断跨事件收益，不能当暴涨跌 |
| 日历与制度 | 开闭市、上市日、板块、历史ST、限价、可卖数量 | 按当日生效规则 | 不统一假定10%限制，制度不全不自动执行 |
| 市场参考 | 指数OHLC、上涨/下跌/平盘/停牌计数、涨跌停计数、统计范围 | 聚合发布日期≤决策时点；范围和分母版本固定 | pool与market不互换；缺失返回blocked |
| 事件 | event_id、首次公开时间、首次可用时间、修订、正文哈希、事件族 | 先去转载/重复公告，再做分类与特征 | 无事前基线不能称超预期；不可用新闻不填中性 |
| 财报与估值 | 报告期、公告时刻、修订版本、行业、财务原始项、股本 | as-of连接，公告前不可见，保存旧版 | PE亏损不适用；按行业选指标，缺项不补满分 |
| 模型预测 | 版本、训练截止、特征哈希、预测时刻、期限、预测值 | 仅使用历史真实样本外预测和成熟结果 | 训练内拟合值不能作组合训练输入 |
| 实例状态 | 现金、持仓、可卖股、预算、风控、资金流 | 决策快照冻结，提交前重新校验 | 研究上限不能视作可执行目标 |

顺序：日历对齐→去重→来源过滤→公司行动处理→可用时间连接→质量标记→特征。禁止先删掉缺失行再假定相邻行是连续交易日。每一输入记录 `source, available_at, fetched_at, revision_id, scope`。

训练段拟合预处理：中位数 $m_j$、稳健尺度 $s_j=\max(1.4826\,MAD_j,\epsilon_j)$，$z_{tj}=clip((x_{tj}-m_j)/s_j,-5,5)$。这里是升级设计；当前近邻采用训练段总体标准差。常量维应删除并记掩码，而不是用极小尺度放大微小噪声。缺失只有在训练前声明允许时才能用训练段中位数加缺失指示；必需情绪、财报、事件缺失一律阻断。预处理器在验证/测试内冻结。

## 3. 市场情绪及特征字典

$$B_t=U_t/(U_t+D_t+F_t),\quad \Delta B_t=B_t-B_{t-1}.$$

停牌不进入有效报价分母，但单独报告数量；当前池内实现用全部同日齐备股票数量为分母，平盘计入，停牌语义仍待完善。$B=0.75$ 代表75%上涨，不能解释成75%上涨概率。

| 特征 | 定义 | 经济含义与限制 |
| --- | --- | --- |
| $R_k$ | $C_t/C_{t-k}-1$，k=5/20/60 | 动量；存在重叠与共线性 |
| $d_{20}$ | $C_t/MA_{20,t}-1$ | 趋势偏离；高值既可能强势也可能过热 |
| $\sigma_{20}$ | 最近20个日收益总体标准差 | 波动，不是最大可损失金额 |
| $RV$ | $V_t/mean(V_{t-20:t-1})$ | 相对成交；零均量为缺失 |
| $DD_{60}$ | $C_t/max(C_{t-59:t})-1$ | 当前距高点，非整段最大回撤 |
| $b_k$ | $C_t/max(H_{t-k:t-1})-1$ | 相对先前高点突破，排除当前日 |
| $\ell_t$ | 跌停数/制度覆盖的有效股票数 | 极端压力；限价制度需历史正确 |
| $a_t$ | $\log(A_t/median(A_{t-20:t-1}))$ | 活跃度；停牌/缺失不可取log |
| $g_t$ | $O_t/C_{t-1}-1$ | 跳空，须调整公司行动 |
| $RS_k$ | 个股k日收益−同区间基准收益 | 相对强弱，基准口径冻结 |
| $Z_j$ | 训练期标准化后的特征j | 统计尺度，不代表概率 |

拥挤代理设计为 $K_t=(Z(R_5)+Z(d_{20})+Z(\log RV))/3$，只作待验证代理，无持仓/资金真值时不能宣称测得“主力拥挤”。避免把成交量、活跃度和拥挤当三份独立信息重复计权。情绪维度分别保留宽度、压力、活跃、文本方向与分歧。极端缺失不得由池内宽度替代。

## 4. 共同收益模型与有限样本推导

设 $y=m(x)+\varepsilon$，$E[\varepsilon\mid x]=0$。局部常数近似 $m(x_j)\approx a$，最小化 $\sum_{j\in N_k(x)}(y_j-a)^2$，一阶条件给出 $\hat a=\bar y_{N_k}$。这解释近邻均值的来源，但局部偏差随距离增大、特征维度升高而增加。

升级线性模型采用岭回归：

$$\min_{b,\beta}\;\frac1n\|y-b\mathbf1-X\beta\|_2^2+\lambda\|\beta\|_2^2.$$

中心化后 $\hat\beta=(X_c^TX_c+n\lambda I)^{-1}X_c^Ty_c$，$\hat b=\bar y-\bar X\hat\beta$。$\lambda>0$ 保证系数块正定且唯一；截距不惩罚，有样本时整个目标也严格凸。用QR/Cholesky求解，不显式矩阵求逆。风险分位采用带岭项的pinball损失：$\rho_\tau(u)=u(\tau-1_{u<0})$，取 $\tau=0.1$；用可验证凸优化器，记录残差和迭代状态。分位数预测不是止损成交保证。

## 5. 预测到资金与B/S

预测毛收益 $\hat\mu$、保守误差项 $u$、成本 $\hat c$，定义 $e=\hat\mu-\hat c-\kappa u$。$u$ 只有经相关性/校准检验后才能称标准误或预测区间；目前 `sd/sqrt(k/5)` 是启发式惩罚，不是置信下界。

设下行尺度 $D=\max(0.02,-\hat q_{0.1})$，实例损失预算 $b=0.005$，持仓上限 $\bar w=\min(0.2,0.8/N)$。由情景损失约束 $wD\le b$ 得 $w\le b/D$。设计参考目标：

$$w^*=1_{gate}\min(\bar w,b/D)\,clip(e/D,0,1).$$

0.5%预算、2%风险地板、20%单股和80%总上限是工程假设，不是最优定理。尾部可能超过D，须另设最大回撤、事件和流动性硬约束。实例配置的模型资金权重是硬授权上限，不是统计融合系数。多模型按股票净额、考虑冲突/相关性后统一校验，不能把独立输出简单叠加下单。

买入候选需完整数据、模型有效、优势门槛和风险通过；持有/卖出需已有持仓快照，$\Delta q=q^*-q$。买入整手向下取整，含费用可用现金复核；卖出不超过T+1可卖股，零股按当时规则处理。次日不可成交时不得在回测硬填计划价。防守退出优先于新开仓，硬风控优先于模型。8%收盘止损是复核触发，不能保证最多损失8%。

## 6. 时间验证、自动调优与发布

采用按时间嵌套滚动：每个外层训练段内部选择参数，外层测试段完全冻结；清除标签跨边界的训练行，对事件族/财报/同日多股按组隔离，防止相关样本跨边界。在最终留出集之前冻结候选族、成本、目标与停止条件。留出集只作独立验收；再次调参后须更换后续未见数据，不再称旧集为未见黄金集。

有限搜索预注册，记录全部试验与无改善结果。候选目标可用成本后平均效用与尾部风险，必须同时报告换手和数据覆盖。当前最多400根日线不足以稳定评估年度稳健性；按试验门槛运行不代表足够发布。分块自助法按连续日期联合抽样全部股票，块长至少覆盖最长持有期限并做敏感性；区间用于不确定性诊断，不能直接证明未来盈利。比较现金、买入持有、简单趋势、固定权重、去情绪版本；去情绪版本另建版本，禁止运行时静默回退。

发布须满足预注册的净收益/回撤/成交可行性门槛、不同阶段稳定性、费用倍增压力、最终留出与前向观察；具体门槛在实验启动前由实例配置冻结，未填写则不能晋升。参数只在重训日更新，限制变化率并保留旧版回滚；不自动放宽风险上限。尚无通过这些验收的AlphaK模型结果。

## 7. “收敛”到底指什么

| 层次 | 可证明/可核验的内容 | 不能推出的结论 |
| --- | --- | --- |
| 数值求解 | 有限搜索必终止；正则凸问题在标准步长与可行条件下收敛全局解 | 全局最优训练误差不等于最优交易收益 |
| 统计估计 | kNN在平稳、适当相关衰减和局部光滑等条件下，k→∞且k/n→0才可能一致 | 固定k=8/16/24、短滚动窗口不满足渐近保证 |
| 非凸模型 | EM使似然不下降（精确E/M步），一般只到驻点 | 不保证真实状态、唯一全局解或投资有效 |
| 交易系统 | 时间外验证与前向记录检验适应性、成本及尾部 | 非平稳市场不存在本文可给出的盈利收敛保证 |

数据越多也可能来自已经失效的旧机制；滚动窗口减少过时偏差却提高方差。收敛分析必须说明对象、假设、停止条件与失败路径。

## 8. 上下文、追溯、失效与实现契约

`冻结实例配置→as-of原始输入→清洗特征→仅成熟标签训练→时间内验证→模型预测→门槛→组合风控→经校验的决策提案`。各层携带 `workspace_id, instance_id(若有), model_id, model_version, code_hash, data_cutoff, input_hash, calendar_version, preprocess_version`，后层不重新抓取新数据混入旧上下文。

输出最少包括：`status, reason_codes, horizon, mu, downside, uncertainty_method, edge, support, feature_values, contributions, gate_trace, target_ceiling, expiry, selected_params, all_trials, provenance`。这是研究建议字段，不能直接提交到严格 `agent-response`/`agent-decision` schema；未来由独立适配器构建schema允许的语义输出，由运行时注入信封，校验后提交。复杂优化不是现有DSL函数，必须新增版本化适配器，不能假装现有表达式已支持。

缺必需数据、日期错位、样本不足、数值不收敛、来源范围改变或数据漂移超阈值时返回blocked并保留原因。测试至少含：修改未来数据不改变过去输出、标签成熟严格检查、复权事件、缺失交易日、极端量价、相同输入可复现、风险上限与T+1。回放只读，季度解释缓存默认8期；过期返回CACHE_EXPIRED，不能影响永久账本。本文不新增表项或变更保留政策；后续落库须同步持久化OpenSpec与harness。

## 9. 方法来源与证据边界

金融假设与访问级别沿用[文献登记](../quant-baseline-literature.md)：R04动量、R05–08情绪与文本、R09状态切换、R10协方差、R11–14推断及多重试验、R01–03质量、R15交互。方法出处补充：Hoerl & Kennard (1970) Ridge Regression，DOI `10.1080/00401706.1970.10488634`；Koenker & Bassett (1978) Regression Quantiles，DOI `10.2307/1913643`；Dempster, Laird & Rubin (1977) EM，DOI `10.1111/j.2517-6161.1977.tb01600.x`。这些补充为经典算法出处，本次未新增全文核验或声称复现。推导为本文给出的有限样本代数及标准优化性质，不是引用论文收益。
