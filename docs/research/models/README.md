# AlphaK 八个量化模型：完整研究文档

版本：design-2026-10-26.1。阅读顺序：公共方法→模型专篇→实现差异。本文档集是研究设计及源码审计，不是已完成训练、回测或部署的声明。量化中心定义模型，不关联个股；实例最多8只股票，禁止全市场扫描和真实下单。

| 模型 | 专篇 | 当前运行状态 | 完整方案的核心方法 |
| --- | --- | --- | --- |
| AK-State | [历史状态学习](ak-state-v1.md) | 七维共享近邻＋宽度门槛 | 局部条件收益、下行风险、成熟标签验证 |
| AK-Regime | [市场状态切换](ak-regime-v1.md) | 共享近邻＋趋势宽度门槛 | 状态过滤概率、分支混合、状态不确定性 |
| AK-Continuation | [情绪确认延续](ak-continuation-v1.md) | 共享近邻＋突破量价门槛 | 独立突破事件、正则回归与情绪交互 |
| AK-Repair | [恐慌后修复](ak-repair-v1.md) | 共享近邻＋回撤修复门槛 | 压力事件、修复概率和条件损益 |
| AK-Cooling | [拥挤退潮防守](ak-cooling-v1.md) | 仅减仓复核，无持仓 | 原仓位保留比例、尾部风险与机会成本 |
| AK-Event | [事件预期与漂移](ak-event-v1.md) | 依赖阻断 | PIT事件、预期基线、可交易漂移 |
| AK-Quality | [质量与时机协同](ak-quality-v1.md) | 依赖阻断 | PIT财报准入、动态择时和交互 |
| AK-Ensemble | [情绪条件模型组合](ak-ensemble-v1.md) | 依赖阻断 | OOF预测融合、凸约束优化 |

每个专篇包含：现有实现、假设、数据处理与特征、数学推导、训练调优、收敛条件、B/S与仓位、情绪参与、验证/失效、上下文与工程验收。

- [公共方法与计算口径](common-methodology.md)：符号、时间、输入表、特征字典、公共推导、A股执行、验证和收敛定义。
- [实现一致性核对与补充清单](implementation-review.md)：发现的问题、源码证据、影响和修复验收。
- [审计源码哈希](implementation-audit.json)：本轮阅读的代码/契约身份；源码改变后必须重新核对，不能沿用本次结论。

收敛结论：有限搜索能结束；正则凸问题在明确条件下有唯一解；HMM仅一般局部收敛；固定k、小样本、非平稳市场不具备本项目可声称的盈利收敛保证。全部数学设计仍需独立实现和真实数据时间外验证。
