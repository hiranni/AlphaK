# AlphaK 基准模型：多因子、市场情绪与验证设计

日期：2026-10-22。状态：数学研究提案 v0.1，未实施、未拟合、无实测业绩。适用：A 股、日频、固定人工股票池1–8只、多头与现金、模拟成交。本文所称「基准模型」是用于比较假设的研究基线，不是基准指数。论文与访问等级见 [文献登记](quant-baseline-literature.md)。

## 1. 核心问题和可证伪假设

研究问题不是「怎样把所有指标加成100分」，而是：在公司质量与价格行为已知的条件下，情绪与预期信息能否增进解释，并在成本后、样本外改善决策？

- H1：质量与估值是不同信息，不能由技术分数代替。[R01–R03]
- H2：情绪的作用依赖股票特征和市场状态，可能出现延续与拥挤后的反转，不能预设越热越好。[R05–R07]
- H3：情绪代理可能只是动量、成交量的重复，必须检验条件增量，而非单独相关性。[R15提供交互动机，不证明本项目增量]
- H4：文本判断可能描述已经发生的即时反应，并不等于可交易的后续收益；模型知识和新闻时点也可能泄漏。[R08、R16–R18]
- H5：复杂度和试验次数越高，越需控制选模偏差；样本外失败是允许且必须报告的研究结果。[R12–R14]

论文结论、本文的工程规则和待验证参数分别登记。任何一个假设失败，都允许保留研究解释但拒绝作为交易依据。

## 2. 记号、时点与样本

i为池内证券，t为交易日收盘判断时点，h为持有窗口，U_v为事先冻结的股票池版本。P^raw为原始价格，P^adj为截至t可知公司行动构建的指标序列。F_t是当时已公开且满足知识截止的输入集合；所有特征x_i,t必须仅由F_t构造。r_i,t为一致全收益口径的日收益，r_m,t为预注册基准收益。

主验证目标使用次日开盘进入、h个交易日后开盘退出的相对持有期收益：

    y_i,t^(h) = R_i(open[t+1] → open[t+h+1]) − R_m(同一时间窗口)

R包含区间公司行动，不能混用当前后复权价和原始成交价。h=1/5/20仅为候选，主终点预注册为5日，其余列为次要检验并计入多重比较；不是论文给出的最优周期。停牌/涨跌停无法成交的样本仍保留在候选集，以执行状态另记，不通过删除失败交易美化收益。无有效终点价格则标签null，报告缺失原因。

研究标签描述潜在价格变化；实际组合收益由资金、仓位、T+1、交易单位、可成交性和费用账本生成，二者不能混称。买入候选的事后涨幅不等于实盘可获得收益。

不把8只股票×交易日数当作全部独立样本。切分、抽样和置信区间按交易日成块，保持同日所有标的相关结构；基本面长期不变也不能被每日复制成大量独立财报证据。

## 3. 双评分的数学定义与界限

原始因子 f_j,i,t 经适用性、有效性与PIT检查后，映射为 s_j,i,t∈[0,100]。默认可复现历史分位映射示例：

    s_j,i,t = 100 × [ Σ_(u∈W_i,t) 1(f_j,i,u < f_j,i,t)
                      + 0.5 Σ_(u∈W_i,t) 1(f_j,i,u = f_j,i,t) ] / |W_i,t|

W仅含t−1及以前有效观测；方向为越低越好的因子取100−s。非单调因子用固定分段函数g_j代替，例如量比过高不必继续奖励。窗口、最小样本、容差与分段节点属于模型版本，不因当前行情临时改变。

初始研究窗口可候选252交易日、最少126个有效值，但属于工程假设。财报只按独立报告/公开事件构造参考集；不能用复制到每日的同一财报假装有126个样本。财报历史不足时使用外部预先固定的经济阈值或保持未评分，不能用8只股票估算“行业百分位”。

    Q_i,t = 0.45 × Quality_i,t + 0.35 × Valuation_i,t + 0.20 × Stability_i,t
    O_i,t = 0.30 × Trend_i,t + 0.25 × Momentum_i,t + 0.20 × Confirmation_i,t
            + 0.15 × Environment_i,t + 0.10 × Safety_i,t

这些组权重沿用产品草案，只是研究假设。每组内部因子和权重必须另行预注册；不可因缺数据自动设等权或归一化。Stability不具治理数据时不得称已覆盖治理。Q与O保持独立，不平均成总分，也不视为收益概率；若O包含情绪环境子项，独立情绪对照必须剔除其重复项后再比较。

对必需因子集合J：任何s_j缺失则该总分null，coverage=Σ有效权重。贡献c_j=w_j s_j，Σc_j必须与总分一致。相对固定参考b_j的贡献为w_j(s_j−b_j)，不能把非负分数贡献都叫利好。行业模型使用不同版本，不在运行中静默移除不适用因子。

## 4. 市场情绪：可观察证据与潜在状态分离

情绪不是价格的同义词，也不是可以直接观测的单一真实数值。V1输出带来源和覆盖的向量：

    E_t = (B_t, A_t, D_t, C_t, ΔB_t, N_t)

B=市场参与方向/宽度代理，A=活跃度代理，D=文本分歧，C=拥挤代理，N=事件文本方向。各项可独立缺失。它们不是经过验证的心理情绪测量，也不命名为官方“情绪指数”。盘面和文本分别保留证据，避免先混合再失去解释。

### 4.1 盘面代理：首版可行层

设U_t、D_t、F_t^count为同一范围同一时点的上涨、下跌、平盘家数，n=U+D+F。与前文信息集F_t不同，F_t^count仅是平盘计数。

    B_t = (U_t − D_t) / n_t ∈ [−1,1]
    ΔB_t = B_t − B_(t−1)

必须声明统计范围、涨跌判断基准、时间和停牌/无效数据处理；范围变化不能直接比较。市场统计与自选样本分别标识，不用样本比例替代全A股。若全市场家数口径不清则B无效。聚合统计是外部输入，不执行全市场扫描。

市场活跃度优先用同口径大盘成交额：

    A_t = log(Amount_m,t / median(Amount_m,t−20:t−1))

只有个股成交时可计算A_i,t，但不能称大盘情绪。历史大盘成交额缺失则保持null，不用池内成交求和代替。

拥挤是难以直接观察的潜在概念。V1只定义需验证的个股追涨拥挤代理：

    C_i,t = max(0, z_(t−1)(R_i,20)) × max(0, z_(t−1)(log VR_i,20))

VR分母不含当天，z是仅由过去/训练窗口确定的标准化。可用中位数和1.4826×MAD构造稳健z，再按预注册边界截断；MAD=0且无可靠替代尺度时输出null，不除以任意小数制造极值。C反映涨幅与异常成交共同偏高，不证明真实持仓拥挤、主力行为或未来必然下跌，也不定义市场级C为8只股票平均。

这些代理本身来自价格成交，会与动量重复，必须经过第7节条件增量检验。仅有当前大盘涨跌家数时只能展示当天状态并从现在积累历史，不能回填旧日期的情绪。

### 4.2 文本情绪、关注与分歧：后续可选层

文本d记录首次可用时间τ_d、实体、原文hash、源、事件族和固定分析器版本。去重按事件族及原始来源进行，转载不能算独立共识。分类器给p_d^+、p_d^0、p_d^-且和为1；q_d为预先固定的来源/标注可靠性权重，不能用后来价格表现决定。

    a_d(t) = q_d × exp(−κ × age_trading_days(t,τ_d))
    N_i,t = Σ_d a_d(t)(p_d^+−p_d^−) / Σ_d a_d(t)
    D_i,t = Σ_d a_d(t)[(p_d^+−p_d^−)−N_i,t]^2 / Σ_d a_d(t)

N是文本方向，D是不同事件/来源观点分歧；D不是模型熵，也不等于所有投资者意见分歧。模型自身不确定性另存entropy=−Σp log p。无文档时N和D为null，不当作中性或无分歧。文本数量/关注度另记，不能当作情绪方向。未经校准的分类概率只是模型输出，不是正确率。[R07、R08、R16]

LLM模型权重/服务版本、提示词、温度、原始响应、人工修订及模型已知训练截止均须冻结。训练截止不明确的现代LLM解释过去新闻，只能标为事后解释性研究，不宣称严格样本外；固定prompt和temperature=0也不保证远程服务逐位复现。正文含外部指令时只作非可信数据。

### 4.3 事件、预期与价格反应

优先定义可核验事件，不把正面词语当成盈利超预期。有可信PIT分析师预测时才计算盈利 surprise；没有时可比较已公开业绩与预先设定基线，但命名为“基线偏离”，不冒称市场预期。

事件τ前估计市场模型，冻结α_i、β_i：

    AR_i,u = r_i,u − (α_i + β_i r_m,u)
    CAR_i,[a,b] = Σ_(u=a)^b AR_i,u

事件日反应、次日以后漂移和可交易回测分别保存。收盘后观察到的CAR不能进入当天收盘前判断。低方差基准/历史不足导致回归不稳定时使用预注册市场调整收益r_i−r_m并明确降级。CAR是市场模型残差，不等于因果效应或可成交收益。[R17]

人工研究另存 hypothesis、supporting_evidence、counter_evidence、confirmation、invalidation、author、created_at及追加修订。事后写的判断不能补成事前特征；除非事先定义标注规则和协议，否则不将自由文本主观判断直接量化加分。

## 5. 市场状态模型与情绪作用

V1使用可解释的两轴状态，而不是“恐惧/贪婪”单值：

    G_t = (index_trend_t, breadth_state_t)

index_trend可由同口径指数close/SMA60−1的符号分为上/下，breadth_state以训练集冻结的B分位阈值分低/中/高。此规则仅描述观测状态，不代表真实隐含经济状态。参数、零值边界和缺失行为预注册；输入缺失时state=unknown。

情绪与策略的假设作用分两种：一是条件交互，例如上涨趋势中宽度改善是否更有利；二是风险限制，例如高涨幅高量比代理下提高观察级别。不能先假定情绪热就加仓，再用同一数据挑出支持结论。

后续可比较Hamilton式隐状态模型：[R09]

    Pr(S_t=k | S_(t−1)=j) = p_jk
    x_t | S_t=k ~ Normal(μ_k, Σ_k)

只用Pr(S_t|x_1:t)过滤概率，禁止以Pr(S_t|x_1:T)平滑概率回填交易信号。初始状态数不自动增加；潜在状态的编号不天然对应牛熊，需固定解释/标签匹配。不在V1用8只股票的小样本训练复杂HMM。

完整的多因子与情绪候选策略决策政策见 [B/S与目标仓位合同](strategy-decision-contract.md)。它是新增挑战者，不覆盖本文件B1简单基线；其中具体阈值属于待验证假设。

## 6. 基准梯度与可执行规则

必须同时保留以下比较层次，以回答增加复杂度是否有价值：

| 版本 | 内容 | 研究作用 |
| --- | --- | --- |
| B0 | 现金、预注册指数、固定池等权买入持有分别报告 | 机会成本和选池条件基线；不同基准不混成一个收益 |
| B1 | 固定MA20/60趋势规则、多头/现金、次日撮合 | 最简单可执行策略，不依赖财报或情绪 |
| B2 | 非情绪低维因子/双评分研究视图 | 检查质量与价格行为的解释增量；分数缺失时不声称完成B2 |
| B3 | B2控制量 + 宽度/活跃度/拥挤代理 + 一个预注册交互 | 检验盘面情绪是否超出动量；不把B3增量全归因心理 |
| B4 | B3 + 文本/预期/人工事前结构化研究 | 有可靠时点与覆盖后才开放，逐模块消融 |

B1规则：新进入close>MA20且MA20>MA60时产生候选；跌破MA20产生退出候选；最多8只、无杠杆，风险与执行约束优先。信号未变不重复下单；止损等风险规则必须独立固定。等权目标以1/|U_v|作为每票预算，未触发部分留现金，不因有信号股票少自动集中全部资金。每笔买入受可用现金、T+1、手数、单票上限及费用约束。B0等权买入持有采用相同初始分配和可成交约束；模拟账本精确核算费用，不用单纯收益相减替代撮合。

B2–B4首先是预测/事件研究对照，不默认已经生成可执行策略。转换为交易策略前，阈值、资金映射、空值行为和执行必须另行冻结；为公平比较，保持同样风控、成本与资金约束，不让“情绪模型”通过额外风险预算获胜。

## 7. 低维条件模型：检验情绪增量

为避免小池过拟合，主挑战者用低维岭回归而非深度学习。主研究h=5：

    y_i,t = α + a_i + β_q q_i,t + β_d d_i,t + γ_b B_t + γ_c C_i,t
            + η [B_t × d_i,t] + ε_i,t

q是预注册的一个质量摘要，d是一个动态摘要；若完整Q不可得，可单独发布无q的降级模型，不能运行时默默删项。A、N、D等不同时无节制加入主模型，而在独立挑战者中逐一检验。股票效应a_i强收缩并施加Σa_i=0，降低同一股票固定差异被误认为择时能力的风险。

在训练期对变量标准化，并最小化：

    Σ_(t∈train) (1/n_t) Σ_(i∈U_t) [y_i,t − ŷ_i,t]^2
    + λ (||β||² + ||γ||² + η²) + λ_a Σ_i a_i²

每个日期总权重相同，避免覆盖多的日期获得更大权重，但这不消除序列相关；推断仍按日期区块处理。截距α不惩罚。λ与λ_a通过训练内部的时间验证从小型预注册网格选择；所有网格尝试计入试验日志。不能随机拆分股票日。

系数贡献是条件线性解释，不是因果解释；同时报告标准化系数、相关矩阵、样本外误差、残差和系数稳定性。不把拟合系数再包装成用户熟悉的100分，避免分数与收益预测混淆。

情绪增量至少比较：

    ΔLoss = Loss_OOS(B2) − Loss_OOS(B3)
    ΔUtility = Utility_net(B3) − Utility_net(B2)

第一项只对有共同标签覆盖的同一日期/标的比较，并报告因共同覆盖丢失的比例；第二项仅在两者都定义了同样可执行资金映射时计算。预测改善并不保证净收益改善；缺标签日的可执行策略仍按自己的预先定义缺失策略处理，不为了对照筛掉亏损日。

也可在训练期将情绪代理对非情绪变量回归后取残差，再在样本外检验；残差化映射必须冻结且线性投影不能证明独立性。V1以嵌套模型和消融为主，避免堆叠多个等价检验挑显著结果。

## 8. 组合风险模型：独立于机会判断

最多8只仍可能高度同向暴露。候选协方差收缩形式：[R10]

    Σ_hat = (1−δ) S + δ × diag(S),  0≤δ≤1
    σ_p² = wᵀ Σ_hat w

此处对角目标是本项目候选，不宣称是原文唯一收缩目标；δ只能用训练窗口确定并版本化。缺同步收益、样本不足或零方差时，不强行反演协方差；V1仍用单票上限、总仓位、集中度和组合回撤硬限制，不以优化器输出替代风控。

Q、O及情绪均不能越过risk=block/critical_unknown、账户资金和交易制度限制。机会分上升不是自动提高风险预算的理由。回放只读，Agent只提交结构化意图，schema与业务校验后由平台执行，禁止直接写订单表。

## 9. 时间验证、统计分析与发布门槛

建议目标数据至少3年，以滚动24个月训练、后续6个月验证/测试形成可执行研究安排；这是工程起点而非统计充分条件。没有足够历史则短期描述研究+前向积累，不用填充数据达标。终版保留未查看的末段测试期；滚动开发中看过的区间不得再称未见样本外。

每个样本有特征时点t和标签结束t+h+1。跨边界时去除标签窗口重叠的训练样本；若交叉验证允许使用测试区间之后的数据训练，还须embargo相应邻近窗口。V1坚持仅用过去训练，不把事后组合CV称为实时收益。参数、分位点、标准化、行业映射均只在训练期确定。

主统计：预测OOS MSE/MAE、相对仅训练均值预测的OOS R²；执行策略的净收益/回撤/换手/交易次数/拒单和现金占比；事件研究的平均/中位数相对收益及区间。没有足够横截面，不给8只股票的日Rank IC包装显著结论。

配对置信区间优先对同日期策略差值做移动区块bootstrap，保留同日所有股票；区块长度预注册且不短于主要重叠标签窗口，并报告多个合理长度敏感性。区块法依然需要平稳性/弱依赖等条件，不能解决重大结构断点。HAC仅用于适用的简单回归对照，不对岭回归系数套普通OLS t检验。[R11]

    对策略日差 d_t = r_net,B3,t − r_net,B2,t，报告 mean(d)、95%区间和累计差异。

所有因子选择、周期、参数网格、源切换、阈值修改都有trial_id；失败试验不得删除。探索阶段控制多重比较并标记探索性，冻结主假设后用新测试集验证；若报告校正p值，声明检验族与方法。Reality Check、DSR是后续专门诊断，当前不输出未经实现的数值。[R12–R14]

研究版发布至少满足：PIT审计通过、可复现、贡献可核对、覆盖和局限可见。交易实验版另需A股执行检查、成本加倍/参数邻域/分年度测试、未见样本外和前向模拟证据。拟合成功不等于验证有效；置信区间跨零或增量不稳定时保留B1，情绪只作为解释与告警，不自动升级策略。

## 11. 工程落地与数学校核

新增概念记录：sentiment_observation（代理、单位、范围、来源、覆盖）、text_event（原文版本及首次可用时间）、research_hypothesis（事前/事后区分）、experiment_registration（主假设与试验族）、model_comparison（共同覆盖与增量）。它们是待实施对象，不能直接添加到additionalProperties:false的既有schema；应另建兼容OpenSpec变更及机读合同。

[数学示例校核脚本](verify_baseline_math.py)只使用构造数值校核宽度、分位并列规则、贡献、情绪方向/分歧和收缩矩阵风险性质；不连接市场、不拟合策略，不构成回测。运行结果见 [数学校核记录](baseline-math-check.json)。

实施次序：先审计输入能否支撑B1与当期情绪展示；积累真实历史快照；再实现因子与解释；通过低维B2/B3样本外对照判断盘面情绪增量；最后才考虑文本、隐状态和复杂模型。没有增量证据时，不因模型复杂就替换简单基线。
