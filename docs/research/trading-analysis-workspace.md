## 分析能力

前5个模型：AK-State、AK-Regime、AK-Continuation、AK-Repair、AK-Cooling 接入共享的历史近邻收益估计器，各自有固定价格与情绪研究门槛。它们是目录模型的试验适配器，不表示完整状态模型、策略回测或验证通过。Regime 当前只作趋势/压力门槛过滤，尚未拟合隐状态模型。Cooling 不开新仓，只提示已有持仓减仓复核；当前没有持仓账本，不生成卖单。

Event、Quality、Ensemble 可选择保存，但对应事件PIT、财报行业适配与子模型样本外预测历史/执行适配器未实现，分析显示受限。大盘历史情绪适配器未实现时，market模式阻断，不能自动替换成pool。pool明示为所选股票池上涨占比，不是全市场情绪或新闻情绪。

## 算法与时间口径

最多400根已完成日线，去除demo/seed/synthetic、周末、已知休市、无效OHLCV。至少180根；个股特征日期必须有全部所选股票的同日宽度。最新日期不齐或超过截止日5个自然日则阻断。交易日历仍不完整，不能据此确认法定交易日；按有效日线观测步生成标签，缺日可能拉长实际期限。

7维状态：5日收益、20日收益、MA20偏离、20日波动、当日量/前20日均量、60日回撤、池内上涨占比。近邻标准化尺度仅由训练窗口估计。标签为下一观测开盘到其后5步开盘的收益，终点严格早于预测时点。候选窗口80/120、近邻8/16/24、谨慎系数0/0.5/1，共18组。过去40步中的每5步验证，至少4次；验证目标为平均条件收益减0.5倍标准差，持币为对照。所有候选评分随报告冻结，尚无最终留出集，不称完整样本外策略回测。

预期净优势=近邻平均收益−0.002−谨慎系数×不确定性。0.002为双边预测成本假设，不是实际成交费用。不确定性按近邻收益标准差除sqrt(max(k/5,1))粗略折算重叠，不是正式置信区间。下行=max(2%,负的历史10%分位)。只有净优势、历史验证、模型门槛均通过才产生买入研究候选。

模型内仓位上限=min(20%,80%/股票数,0.5%/下行)×clip(净优势/下行,0,1)；账户参考上限再乘用户配置的策略资金权重。没有现金/整手/T+1/持仓校验，这些是研究上限而非可执行目标。退出政策只作说明：5步期限、8%收盘风险复核或门槛失效需重新分析，不自动撮合或卖出。

## API 与持久化

- GET /api/v1/trading/research：最近100配置及各自最新报告。
- POST /api/v1/trading/research：名称、symbols、allocations[{model_id,weight}]、sentiment_scope。未知字段、超过8只、重复、未知模型、非有限/非法权重及总权重超限由后端拒绝。
- POST /api/v1/trading/research/{id}/analyze：读取配置，冻结行情与模型定义/代码指纹，锁外计算。并发上限1，相同语义输入和截止日复用报告。

research_workspace/research_analysis 持续保留，纳入备份和harness，不参与TTL清理。报告保存来源与采集时间、18组评分、最近5个相似历史日期和标签成熟日。刷新采集时间不会单独制造重复报告。配置和研究报告不冒充 strategy-instance.schema.json 的账户/Agent执行实例；不创建真实或模拟订单，也不展示虚构净值。

## 账户管理操作（2026-10-26）

实盘首页提供账户列表、新建账户、显示归档账户和进入账户。账户内部：概况、股票与策略、训练与验证、B/S与记录。新建账户复用研究配置表单，设置初始模拟资金；保存账户策略生成新workspace并原子换绑，资金不变，旧版配置和报告保留。归档/恢复保留账本。当前每账户一个研究配置、配置内多个模型权重，尚非多策略独立子账本。

PATCH `/api/v1/trading/paper-strategies/{id}` 接收action archive/restore/reconfigure（换版需config）；GET `/{id}/events` 返回操作历史。归档账户禁止换版。账户内分析显示真实数据阻断原因，B/S区域仅展示研究判断，不虚构成交点位。黄金测试集、完整回测和自动撮合仍未实现，页面明确标注。
