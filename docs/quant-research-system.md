# AlphaK 量化研究体系设计

日期：2026-10-22。状态：研究架构提案，尚未实现，不替代现有 JSON Schema。范围：A 股、收盘后日频、本地单用户、免费数据优先、固定人工股票池。本文将用户提出的五层架构和四项原则落实为工程边界；权重和交易规则是待验证假设，不代表已有策略表现。

## 1. 定位与边界

研究对象是「公司质量、估值预期、市场行为、风险环境」四个独立维度；输出为投资质量分、市场机会分、独立情绪与预期状态、独立风险状态和规则事件，禁止合成一个掩盖风险的总分。好公司、好价格、好时机、低风险不能互相替代。

第一阶段市场已确定为 A 股，不再重新选择美股或双市场。股票池人工指定且版本化，每策略 1–8 只、持仓不超过股票池数量；禁止全市场扫描或排名。大盘聚合涨跌数据可作为环境输入，不能借此扫描全市场。用户可见「实盘」始终是模拟资金与模拟成交，无券商或真实委托。

可回溯：每个结果关联不可变输入、配置、代码和日历版本。可解释：原始值、变换、方向、权重、贡献和限制可展开。可量化：指标公式、单位、时点和空值行为唯一。可分析：研究检验、成本、样本外及稳健性报告绑定具体版本，不覆盖旧结果。

## 2. 五层职责与数据流

| 层 | 输入与职责 | 输出与边界 |
| --- | --- | --- |
| 数据基础 | 行情、财报、估值、公司行动、事件、基准及交易日历；来源适配、版本和可用时点检查 | 不可变输入清单与质量报告；不计算买卖结论 |
| 因子引擎 | 已冻结输入和因子定义；行业适用性、窗口、标准化与质量检查 | 原始值、标准化值、有效性、解释；不下单 |
| 研究与决策 | 因子、模型、规则及风险约束 | 双评分、池内比较、候选信号和独立风险裁决；评分不等于事件或订单 |
| 验证与分析 | 锁定版本、股票池、数据及运行假设 | 回测、事件研究、样本外、归因与稳健性报告；不回写历史模型 |
| 策略应用 | 经审核的策略版本和实例绑定 | 自选研究视图、模拟运行、订单意图；平台校验风控后模拟撮合 |

顺序：冻结数据与事前研究假设 → 计算因子 → 双评分及独立情绪/预期状态 → 判断规则事件 → 风险过滤 → 决策校验 → 模拟订单 → 撮合与账本。回测复用同一因子和规则实现，使用独立回测时钟与撮合器。研究报告只能读运行与账本数据。

## 3. 数据时点与可复现合同

每条数据至少区分 `observation_period`（经济归属期）、`published_at`（实际公开时间）、`effective_at`（该修订生效时间）、`ingested_at`（本机采集时间）。同时记录 source、source_record_id、revision、payload_hash、unit、currency、质量状态。旧版本追加保留，不用当前值覆盖历史。

一个运行固定两条时钟：`as_of` 是研究/交易判断时点，`knowledge_cutoff` 是允许使用的采集版本截止时点。实际历史运行要求 published_at、effective_at、ingested_at 均不晚于对应截止时间。事后下载的历史资料可用于事后历史重建，但必须证明当年公开时间与修订版本，标为 `historical_reconstruction`，不能声称是当年实际持有的数据。无法证明版本的资料禁止用于严格 PIT 回测。

只有公告日期而无时间时，保守安排到公告日之后的下一交易日开盘可用；若未来拿到精确时间，须新版本记录，不悄悄改变旧结果。更正财报不得替换更正前已冻结的输入。财务指标必须继承所依赖报表的可用时间，不允许用当前 ROE 搭配历史价格。

行情保存原始交易价格、成交量口径、复权因子及公司行动版本。技术指标使用截至 as_of 可知且以当时锚点构建的一致复权序列；模拟成交使用原始价格。分红、送转、拆并股分别进入现金/股数账本，不能又使用含分红收益又再次入账。收益基准采用同样的价格/全收益口径并显式标识。

股票池保存生效区间、选择原因、冻结时间和成员清单。今天挑出的股票倒推历史仅称「当前固定池的条件性历史研究」，不声称历史选股能力或无幸存者偏差。退市、停牌证券保留在历史池中。日期以交易日历对齐，存储 UTC，展示 Asia/Shanghai。

数据源 A 失败可换 B，但必须逐字段检查单位、复权、公告时间、历史修订和覆盖范围，禁止静默拼接。跨源切换生成新输入版本并标出断点；源名不是独立性的证明。免费接口缺少历史估值、财报修订、公司行动或历史市场宽度时，明确 unavailable，不能用今日值填补历史。宏观和分析师预期 V1 不作为必需输入。

## 4. 四维研究与双评分

| 研究维度 | 含义 | 首版候选数据 | 不适用情形 |
| --- | --- | --- | --- |
| 基本面质量 | 成长、盈利、现金实现与经营持续性 | 营收同比、ROE、经营现金流/净利润 | 负基数增长、净利润非正、行业口径不同 |
| 估值与预期 | 价格隐含预期 | 正盈利 PE、PB、自身历史分位 | PE 非正、净资产非正；缺预期数据则不声称覆盖预期 |
| 动态市场行为 | 趋势、动量、成交确认 | MA20/60、20/60 日收益、基准相对收益、量比 | 窗口不足、复权不完整、停牌、量口径冲突 |
| 风险与环境 | 个股、组合、事件及大盘风险 | 波动率、回撤、流动性、指数趋势 | 历史环境数据缺失、事件覆盖不完整 |

质量模型初始预算：基本面质量 45%、估值与预期 35%、财务稳定性与治理风险 20%。第三项单独承担偿债/稳定性/治理，第一项不再重复计负债等指标；治理数据缺失必须明确覆盖缺口，不能仅用低负债声称治理良好。

机会模型初始预算：趋势 30%、动量 25%、成交确认 20%、市场环境 15%、短期安全条件 10%。这些仅为研究配置草案，未经样本外检验不可作为默认可部署策略。暂不发布最终子因子权重；必须先验证每项数据与适用性。

所有标准化分数范围 0–100，统一越高越有利；原始风险量保留「越高越危险」含义，经显式单调反向映射才能作为安全条件分。独立风险状态为 pass / warn / block / unknown；critical 输入缺失时 unknown 阻断自动执行，不能被高分抵消。

完整模型 S = Σ(w_i × s_i)，Σw_i = 1；贡献 c_i = w_i × s_i，必须以未四舍五入精度验证 Σc_i = S，展示舍入差额单独说明。正负贡献定义为 w_i × (s_i − b_i)，b_i 为模型固定参考分（初始可设 50），避免所有非负贡献被误称正向因素。总分、相对参考贡献、原始经济含义分开展示。

缺失禁止填零、填满分或自动重分配权重。首版完整总分仅在全部必需项有效时输出；否则 total=null，展示有效子项和 coverage=Σ有效项权重，不计算可排序的「半成品总分」。行业不适用使用提前定义的独立模型版本，不能运行时临时删项。过期标准是因子配置的一部分，以交易日/报告周期计，不使用全局统一天数。

高/低区间阈值需版本化和验证，未冻结前只展示连续值。四象限仅是研究分类，不生成买卖意图。

### 4.1 情绪与预期是独立研究视角

情绪贯穿数据、因子、条件决策、验证与策略应用，不是简单追加一个越热越好的分数。大盘、行业/题材和个股分别研究；当前缺乏题材成员历史、新闻或盘中数据时标记未覆盖，不用日线推断回封、资金意图或完整盘中博弈。大盘聚合输入与池内样本明确区分。

首版保留宽度方向、成交活跃度、变化方向，以及个股量价拥挤代理；后续有可靠文本数据再加入事件方向、来源分歧与关注程度。它们是市场行为或文本证据代理，不等于直接测得投资者心理。拥挤、分歧和模型不确定性不是同一变量。强势情绪可能有利延续，也可能增加过热风险，作用必须结合策略和状态验证。

消息事实、预期基线、消息后的市场反应、可交易的后续表现分别记录。人工假设保存支持/反对证据、确认/失效条件、作者和当时时间，追加复盘，不允许事后补写成事前判断。无法证明预期数据时，不声称「超市场预期」。

数学定义、论文依据与分层实验见 [基准模型](research/quant-baseline-model.md) 和 [文献登记](research/quant-baseline-literature.md)。这些是研究提案，不表示模型已拟合或得到超额收益。

## 5. 首批因子字典与标准化

以下为待实现的原始因子定义；标准化阈值、适用行业与验证记录属于版本发布必填项，缺少时只能展示原始值，不输出标准化分或双评分。

| 因子 ID | 公式/窗口 | 单位与方向 | 有效性与时点 |
| --- | --- | --- | --- |
| revenue_growth_yoy | 同口径累计营收/去年同期累计营收−1 | 小数，通常越高越有利 | 上年营收>0；对应两份已公开报表 |
| roe_ttm | TTM 净利润/期初期末平均净资产 | 小数，通常越高越有利 | 净资产>0，季度拼接及归母口径需固定 |
| cash_conversion_ttm | TTM 经营现金流/TTM 净利润 | 比率，区间映射 | 净利润>0；极端值不直接奖励 |
| leverage | 总负债/总资产 | 小数，较低通常有利 | 资产>0，金融行业不套用一般企业模型 |
| pe_ttm | 当日市值/当时可知 TTM 盈利 | 倍数，非简单越低越好 | 盈利>0；历史价格与股本均须 PIT |
| pb | 当日市值/当时可知净资产 | 倍数，行业条件化 | 净资产>0，金融行业另行定义 |
| trend_spread_20_60 | SMA(close,20)/SMA(close,60)−1 | 小数，趋势方向 | 60 个有效日线，统一复权 |
| momentum_20 | close[t]/close[t−20]−1 | 小数，动量方向 | 21 条有效日线 |
| relative_return_20 | 个股20日收益−基准20日收益 | 小数，相对强度 | 同日历、同收益口径 |
| volume_ratio_20 | volume[t]/mean(volume[t−20:t−1]) | 倍数，区间/条件映射 | 至少21条，同源同股数口径，均值>0 |
| volatility_20 | std_sample(log收益,20)×sqrt(252) | 小数，原始越高风险越大 | 21条价格、样本标准差 ddof=1 |
| drawdown_60 | 1−当前复权价/max(最近60条复权价) | 小数，原始越高风险越大 | 不等于策略净值最大回撤 |

标准化优先采用版本化分段阈值映射，或个股自身过去窗口经验分位。历史分位参考集截止 t−1，窗口长度、最小样本、并列值及截尾规则固定；阈值训练仅用训练集。8 只股票的池内排序可展示，但不能标为全行业排名。行业百分位及横截面 IC 不在 V1，避免用极小样本给出貌似可靠的统计。

## 6. 研究记录与逻辑数据模型

本节是概念模型，不是数据库迁移或已上线 API。

| 实体 | 关键内容 | 不可变与关联 |
| --- | --- | --- |
| data_revision | 实体、字段/数据集、公开/生效/采集时间、源与校验和 | 原始内容按哈希保存，修订追加 |
| universe_version | 人工清单、选择时点、有效区间、历史偏差标签 | 每策略1–8只 |
| factor_definition_version | 公式、单位、方向、窗口、适用行业、空值/过期、标准化 | 发布后不可变 |
| model_version | 因子版本、映射、权重、参考分、关键输入、阈值 | 配置哈希和代码版本 |
| input_manifest | 数据修订清单、时间截止、日历、复权与基准、数据质量 | 内容寻址，禁止指向浮动 current |
| research_run | 池、模型、输入、运行方式、构建/依赖/随机种子与时间 | 幂等键基于内容，不以时间戳伪造唯一计算 |
| factor_observation | run、标的、原始/标准化值、状态、来源与覆盖 | 同run固定结果 |
| score_snapshot | run、标的、双评分、贡献、覆盖、风险及限制 | 结果不覆盖，纠错创建新run |
| signal_event | 规则版本、触发时点、条件真值、解释、失效条件 | 事件及状态迁移追加留痕 |
| validation_run/report | 数据切分、基准、成本、指标及样本量 | 绑定策略/模型/池版本 |
| strategy_version/instance | 沿用现有策略及实例契约 | Agent绑定仅在实例 |

复现身份由 universe_version、model_version、factor版本、input_manifest_hash、代码/依赖构建、日历/撮合/成本版本共同确定。状态区分 complete / partial / failed；复现能力单列 reproducible / snapshot_missing / unsupported，不能因为已保存最终分数就标为 reproducible。缓存生命周期继续使用现有 schema 的状态，不混成上述计算状态。

详细输入、因子和解释按现有季度缓存策略管理（默认8季度，可固定保留）。长期保留最小元数据、哈希、版本与删除墓碑；清理后输入不全必须返回 CACHE_EXPIRED，不能承诺永久可重算。需要长期完整复现的研究须 pin 所有依赖或导出完整校验包。净值、持仓、资金与交易账本不属于缓存，绝不随解释缓存清理。

## 7. 策略生命周期与执行合同

策略逻辑版本、验证证据、运行实例分开。沿用当前策略 schema 的 draft → validated → active / paused → archived，实例使用 draft / running / paused / stopped / archived；新增研究审核标签是关联证据，不另发明冲突枚举。

- draft：语法、因子适用性、数据可用性和规则审查。
- validated：至少 schema+业务校验、PIT检查、成本回测、冻结样本外及参数稳健性有明确结论；通过计算不等于盈利达标。发布签名/证据哈希固定。
- active：策略可供创建实例，不能据此认定实例正在交易。实例 running 需独立人工确认、账户资金、Agent版本及风控通过。
- paused：平台硬风控可暂停实例；恢复必须人工复核。不因重跑任务自动恢复。
- archived：不再新建实例，保留既有研究、版本和账本。

发布后逻辑及参数不可变，调整产生新 SemVer。状态变化作为独立审计事件，不能修改版本内容哈希。当前 schema 尚未表达完整证据与内容哈希；实际实施时须新增关联对象/兼容迁移，经 OpenSpec change 更新 schema和示例，不能直接往 additionalProperties:false 的现有对象塞字段。

首条闭环策略建议采用既有均线趋势示例：收盘>MA20且MA20>MA60产生进入候选，跌破MA20或止损产生退出候选，次日开盘尝试模拟撮合。前20日突破可作第二条对照。双评分初期作为旁路研究信息，不在未经验证时强行加入交易条件；没有可靠基本面历史仍可验证纯技术闭环，但不能声称完成多因子研究MVP。

信号事件仅在规则 false→true 时生成，同一实例/规则/标的/判断bar去重；失效、过期、确认和风险拒绝分别留痕。数据不足是 unknown，不是规则 false，更不能生成反向退出信号。信号不是订单，风险通过也不保证成交。

买入、持有、加减仓、退出及目标数量的完整研究草案见 [策略决策合同](research/strategy-decision-contract.md)。本文均线示例仍为对照基线；新草案阈值不代表已验证参数，当前schema尚不能直接执行。

## 8. A 股回测与分析口径

收盘后计算，默认下一交易日开盘撮合，不用已知收盘价同时生成并成交。T+1、100股买入单位及卖出零股、停牌、ST/板块/上市阶段差异、涨跌停与委托可成交性使用带生效日期的规则表，不能把当前10%规则应用于所有历史证券。仅有日线不足以证明涨停可买或跌停可卖时采取保守拒单，并记录原因；不虚构队列成交。

使用按日期生效的佣金、最低佣金、印花税、过户费与显式滑点/成交量参与限制；费用方案冻结进运行。缺交易规则或公司行动数据时降级为研究性回测，不允许标为完整可执行结果。

年化收益按净值起终点与实际跨度计算；波动率及 Sharpe 按净值交易日收益和252年化，风险利率及来源显式给定；最大回撤以净值历史高点为分母。胜率与盈亏比按已闭合交易计算并固定分批平仓配对法；零亏损/零方差时相关比率为null。报告保留公式版本、有效天数和交易次数。基准、空闲现金、费用及分红处理同时披露。

训练、验证和样本外按时间切分并冻结；标签重叠时 purge + embargo，隔离长度由持有期/标签窗口决定。标准化、参数和阈值只在训练区间拟合，样本外禁止反复调参；再次查看后调参的区间只能称验证集，需新的未见区间或前向模拟。

V1优先做池内事件研究（1/5/20交易日后收益、相对基准收益、样本数、重叠事件处理）与策略成本回测。没有足够独立样本时报告样本不足；极小股票池不输出可靠横截面IC结论。事件收益仅作统计描述，不能证明可成交或因果。

稳健性报告覆盖不同年份/市场阶段、参数邻域、提高成本、缺失数据与替代源；披露尝试过的参数数和失败结果。归因先做可核对的标的贡献、费用、持有期及基准分解；未建立合格风险模型前，不把粗略相关性称为行业/风格因果归因。

## 9. 当前工程差距与实施顺序

代码核对：quote_daily 主要按标的和日期覆盖保存，尚不足以承载不可变行情修订；financial_report 已有版本、announce_date、effective_at、hash和collected_at，是基础但不证明来源历史完整；financial_indicator 尚无同等版本时间结构，不能直接用于严格历史评分。自选 workbench 当前 score 是四条技术条件各25分的规则符合度，应保留原语义，不迁移成质量或机会分，也不能换名后宣称已经实现双评分。

| 阶段 | 交付 | 完成门槛 |
| --- | --- | --- |
| R0 数据能力审计 | 固定池、字段来源与PIT覆盖矩阵 | 对每项记录真实样例、修订与公开时间证据；缺口显式标记 |
| R1 时点快照 | 修订、输入清单、质量检查、复现工具 | 后公告/后修订无法进入早期运行；同输入可重复 |
| R2 因子研究 | 少量原始因子及解释链、标准化版本 | 单位/空值/适用性明确，贡献可核对；不能评分时不评分 |
| R3 模型与规则 | 双评分研究版本、版本化信号 | 缺失和风险不被高分掩盖；数据支持不足保持partial |
| R4 验证闭环 | 一条技术策略、真实成本、样本外及事件研究 | 无前视、交易约束可审计、参数/费用敏感性可检查 |
| R5 模拟前向 | 单账户子账本、实例校验、日频运行与解释 | 与回测同规则；订单可追溯，回放只读，缓存清理不伤账本 |

所有后续阶段都是待办，不代表当前已交付。前端由上述对象推导：个股研究以双评分/情绪与预期/风险/覆盖为首屏，展开原值与贡献；策略页展示冻结版本和证据；回测页展示运行清单、分区结果及限制；实盘页只读对应实例的模拟账本。

## 10. 设计验收场景

1. 6月30日报告7月20日公开：7月1日回测不见该数据；晚间公告不会提前进入当天收盘信号。
2. 事后更正盈利：旧run输入哈希与得分不变，新run明确引用更正版；当前指标不泄漏进旧run。
3. 缺一项必需因子：总分null、覆盖减少、关键风险unknown阻断；不重新分配权重。
4. 每个分数的贡献和等于总分；风险反向映射与原始风险方向可核对。
5. 相同内容/版本重算结果一致；更换源、复权、日历或成本产生新run和可比较差异。
6. 次日停牌或不可成交涨跌停：候选信号保留，但模拟订单拒绝/待处理，不产生虚构收益。
7. 修改策略参数产生新版本，旧样本外报告不变；策略active与实例running分别展示。
8. 删除季度解释缓存后回放返回CACHE_EXPIRED；净值和交易账本仍完整且不可由回放修改。

需要实施前冻结的研究参数：首批1–8只股票清单、可获得历史长度、基准、行业模型适用范围、标准化阈值和子因子权重。当前可先做数据审计，不以这些参数未定阻断设计，也不擅自将草案参数发布为生产模型。

## 11. 自动运行与调优优先级更新

优先建立可运行实验闭环，而非等待完美多因子策略。按独立能力版本先运行技术T0，再增加盘面情绪T1、基本面T2和文本T3；缺失能力明确降级命名，禁止静默绕过条件。有限参数搜索、时间验证、无改善保留原版、影子运行及晋升政策见 [策略自动调优](research/strategy-auto-tuning.md)。R0–R5可在能力隔离前提下迭代推进，不把全量财报/情绪数据齐备作为首轮技术实验前提。
