## 后续功能验收要求

- 总览：策略数量及状态、今日信号状态、最近回测、模拟组合、数据健康及待处理事项；策略表现对比、信号时间线、异常和回测记录由真实服务提供。最近回测、样本外验证和模拟运行分别统计，不合并成一个收益率。
- 策略：基本资料、入场退出规则、仓位与风险约束、版本及生命周期。修改规则或阈值产生新版本，历史回测和实例固定引用版本；策略定义不声明 Agent，绑定保留在实例。详情与编辑、复制、启停、回滚功能尚未实现。
- 因子：趋势、动量、成交量、估值、风险状态与规则事件分离；仅用户指定股票池，每策略最多 8 只，不做全市场扫描或排名。因子相关性、分组未来收益和样本外稳定性必须经验证任务产生。
- 回测：锁定版本、股票池、基准、日期、日频数据和交易成本，记录复权、分红、退市及历史成分股处理口径；训练、验证、样本外区间分别记录。净值、基准、回撤、年化、Sharpe、胜率、盈亏比、换手率、逐笔交易和参数敏感性均需要真实计算。其他频率在数据与引擎支持后开放。
- 实盘：账户资金分配、策略实例及子账本、模拟订单、持仓、净值及运行留痕。所有 Agent 决策经 schema 与业务校验后进入执行流程，禁止 Agent 直接写订单表；分析缓存清理不能删除账本，回放只读。
- 信号：策略版本、标的、周期、触发时间、依据、失效条件、风险与状态历史；评分不作为预测准确率。通知与冷却控制后续接入。

实现上述服务前，应遵循 `AGENTS.md` 和 `docs/specs/README.md`，按 OpenSpec 流程细化变更。
