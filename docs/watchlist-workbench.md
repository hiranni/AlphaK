# A 股自选工作台

入口：`/watchlist`。本期只覆盖用户自选中的 A 股，不做全市场扫描，不产生真实订单。

## 页面与数据

- 市场概览使用现有 A 股指数接口；自选涨跌、覆盖率按证券去重。
- 自选列表支持当前分组内搜索、重点关注、突破/波动/信号筛选、排序、可选列、紧凑/详细模式、批量添加删除，以及原有分组、备注、CSV 和手动拖动排序。
- 快捷分析展示日线、均线、前 20 日高低点、波动率及信号依据；可继续打开完整个股页。
- 列表和信号采用已完成交易日日线，不是实时逐笔行情。显示来源、日期、缺失及过期状态。盘中价格变化不会立即触发日频提醒。当日日线还须有收盘后抓取时间，盘中缓存不会在收盘后自动视为完整日线。
- 演示行情不参与分析。复权信息不足时不计算涨跌幅和价格技术信号；同源成交量不足 21 日时不计算量比，也不生成完整评分。不同提供商的成交量单位不直接比较。

## 规则符合分 v1

需至少 60 条连续真实且可复权日线及可比较的量比。四项条件各 25 分：收盘价高于 MA20、MA20 高于 MA60、20 日收益为正、当日量达到此前 20 日均量的 1.5 倍。缺失数据留空。

这是规则满足程度，未经绩效回测，不表示上涨概率、预测准确率或投资建议。趋势突破以当前收盘价与此前 20 日最高价比较，不将当日最高价纳入门槛。历史年化波动率为最近 20 个对数收益的样本标准差乘 √252。

## 提醒

提醒规则存于 SQLite，支持价格上下阈值、日涨跌幅、量比、突破前高、跌破前低及历史波动率。每分钟由运行中的后端检查，只有新鲜的真实已完成日线才可触发。每规则每交易日最多记录一次，另遵守 1–10080 分钟冷却时间。暂停、编辑、删除均可用；删除规则保留历史触发记录。标的移出所有自选后暂停计算。

站内历史在关闭页面后仍由运行中的后端记录；浏览器通知需用户主动授权、页面保持打开。首次开启不补发历史通知。邮件、移动推送、财报/新闻事件提醒、自定义策略触发尚未接入。后台停止时不会检查提醒；本功能不承诺实时送达。

## API

- `GET /api/v1/watchlists/workbench`：自选范围的只读日线分析。
- `GET /api/v1/watchlists/alerts`：规则与最近 100 条触发记录。
- `POST /api/v1/watchlists/alerts`：创建规则。
- `PUT /api/v1/watchlists/alerts/{id}`：编辑或暂停规则。
- `DELETE /api/v1/watchlists/alerts/{id}`：删除规则，保留历史。

创建/编辑字段：`symbol`、`kind`、`threshold`、`cooldown_minutes`、`enabled`。`kind` 为 `price_above`、`price_below`、`change_above`、`change_below`、`volume_ratio`、`breakout`、`support_break` 或 `volatility`。符号必须属于当前自选，规则总数上限 200；返回统一 API envelope。

### 自选历史自动补齐（2026-10-22）

工作台读取时检查自选股有效复权日线是否达到 60 条及同源量比是否可算。不足时在后台请求过去 365 个自然日的真实日线及复权数据，复用行情源降级链；读取不等待网络。仅处理用户自选，不扩展到全市场。每只股票失败/不足后至少间隔 5 分钟再尝试，任务单实例运行；已有真实数据不会以演示数据补足。

`technical_bars_count` 表示实际可用于技术分析的尾部连续有效复权日线条数，区别于 `bars_count`。21 条起可计算 MA20 与相关信号；60 条起可计算 MA60 趋势；评分还要求同源成交量比可用。表格显示具体条数与 `history_status`，不再把分析数据不足显示成“暂无条件触发”。同步状态缓存于 `live_cache` 的 `watch_history` 数据集。


## 自选集合与分组（2026-10-23）

- “全部自选”是默认、固定入口，按股票代码去重；即使没有任何自定义分组也能添加、查看、排序、编辑备注和取消关注。
- 自选集合在现有 API 中使用固定 ID `watchlist-all`，位于返回列表首位；不计入自定义分组数量，不可删除、重命名或修改颜色。
- 为兼容现有客户端，集合仍复用 group/item 返回结构。收藏记录由固定集合持有，自定义分组只提供归类。新增到任意分组时，在同一事务中先确保股票属于全部自选；重复添加不覆盖原备注或生成重复记录。
- 删除自定义分组、清空分组、从分组移除股票，仅删除对应归类，不取消关注。删除最后一个自定义分组也允许。
- 从全部自选取消关注，会在同一事务中同时移除该股的所有分组归类；清空全部自选的 API 同理。行情、样本和其他历史研究数据保留。
- 可勾选股票，点击“加入分组”，选择目标分组；股票允许跨组归类，重复操作不增加重复记录。
- 首次升级时创建固定集合，并按原创建时间、排序和 ID 从既有分组记录中确定性选取每股首条备注用于自选集合；原分组与各自备注不变。集合备注与分组备注独立，删除分组会删除该分组自己的备注。
- 升级迁移幂等；自定义分组为空或全部自选为空均为合法状态。行情和量化信号按股票去重。
